# Пазл

Курсовая работа по дисциплине «Компьютерная геометрия и графика».
2D-игра на Unity 2022.3.62f3: игрок перетаскивает кусочки изображения и собирает из них целую картинку.

Автор: Шашелов Артём Владимирович, группа О-24-ИСТ-итпк-Б.

## Возможности

- 6 встроенных уровней и 3 сложности: 3×3, 4×4, 5×5;
- загрузка своего изображения (PNG, JPG);
- таймер и система очков: +10 за фрагмент на своём месте, −2 за ошибку, −5 и −15 за подсказки, бонус за скорость, рекорды;
- подсказки: показ исходной картинки и установка фрагмента на место;
- пауза (кнопка «Пауза» или Esc);
- сохранение и загрузка игры в 3 слота;
- настройки в меню и в игре: громкость, разрешение, полноэкранный режим, сетка на поле;
- плавные переходы между меню и игровым полем.

## Как открыть

1. Добавьте папку проекта в Unity Hub (Add → Add project from disk) и откройте её в Unity 2022.3.62f3.
2. При первом открытии проект сам создаст сцены `Assets/Scenes/MainMenu.unity` и `Assets/Scenes/Game.unity` и добавит их в Build Settings. Если этого не произошло, выберите в меню **Puzzle → Пересоздать сцены**.
3. Откройте сцену `MainMenu` и нажмите Play.

Сборка: File → Build Settings → Windows → Build.

## Структура

| Папка | Содержимое |
| --- | --- |
| `Assets/Scripts/Core` | Сохранения, настройки, очки, таймер, звук, переходы между сценами, загрузка изображения |
| `Assets/Scripts/Puzzle` | Игровое поле, фрагменты, подсказки, управление игровой сценой |
| `Assets/Scripts/UI` | Создание интерфейса, главное меню, окна настроек и сохранений |
| `Assets/Scripts/Editor` | Автоматическое создание сцен и настройки импорта картинок |
| `Assets/Resources/Levels` | Картинки встроенных уровней |
| `Tools` | Скрипт на Python, которым нарисованы картинки уровней |

Сохранения лежат в `%USERPROFILE%\AppData\LocalLow\Shashelov\Пазл\saves`.
